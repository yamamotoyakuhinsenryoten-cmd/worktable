# 要件定義: Instagram投稿キャプションへのタグ自動追加

- 作成日: 2026-11-22
- 対象: work・experienceログのInstagram投稿（developmentは対象外）
- ステータス: 確定（2026-11-22）

## 1. 背景・目的

Instagram投稿時にキャプションへ手でタグを付けるのは手間がかかる。ログの種類と内容から、タグを自動で付けられるようにする。

固定タグで投稿の傾向を安定させ、ログ内容から生成する動的タグで個別の投稿内容に合わせる。

## 2. 対象と非対象

- 対象
  - work（焙煎・縫物・染物）とexperience（コーヒー店・コーヒー豆）のInstagram投稿
  - 投稿キャプションへのタグ追加
- 非対象
  - developmentログの投稿
  - 投稿画像の選択、投稿順、投稿フローの変更
  - タグの確認画面や手動編集（自動で付ける。確認は不要）
  - インスタで実際に使われているタグの調査（別タスク）

## 3. 変更箇所（想定）

- `lib/instagram.ts`
  - `buildInstagramCaption`：タグ生成を追加し、キャプション末尾に付ける
  - `InstagramLog` 型：`category` を追加する（現状の型にない）
- `tests/instagram.test.mjs`：キャプションの期待値を更新し、タグのケースを追加する
- 投稿API（`app/api/post-instagram/route.ts`）：`buildInstagramCaption` の呼び出し元。現行の実装に合わせて、`category` を渡せるか確認する（未確定事項 2 を参照）

## 4. 機能要件

| ID | 内容 | 根拠 |
|---|---|---|
| R-01 | キャプションの末尾に、空行を1つ入れてタグ行を追加する | 会話で「キャプションの一部として含める」「詳細と考察の後ろに空行」 |
| R-02 | タグ行は1行にスペース区切りで並べる | 提案どおりに確定 |
| R-03 | タグは「固定タグ」→「動的タグ」の順に並べる | 提案どおりに確定 |
| R-04 | 固定タグは、ログのカテゴリごとに次の一覧から付ける（下の表） | 会話で固定タグ案を提示し、「いったんOK」 |
| R-05 | 動的タグは、カテゴリごとに次の項目から生成する（下の表）。項目が未入力、または空欄のときはその項目からタグを作らない | 会話で「グレード」「対象」「エリア」を入れる、「未入力ならタグは作らない」を確認 |
| R-06 | 動的タグの値は、前後の空白を除き、空白を詰めて1タグにする | 提案どおりに確定 |
| R-07 | 動的タグの値が「、」区切りの場合は分割し、それぞれをタグにする（コーヒー豆の産地） | 表の定義（提案） |
| R-08 | タグに使えない記号（・ ( ) （ ） ＠ | ｜ など）は除去する | 提案どおりに確定 |
| R-09 | 店名は「＠」「(」「（」より前を店名、後ろをエリアとして扱う（コーヒー店） | 提案どおりに確定 |
| R-10 | タグは大文字小文字を区別せず、重複を除く。固定タグと動的タグで重複したら、先に出てきたものを残す | 提案どおりに確定 |
| R-11 | タグの数は最大30個とし、超える場合は動的タグを先に切る（固定タグは残す） | Instagramの上限（30個）と提案どおりに確定 |
| R-12 | タイトル内の「#6」などの連番は、キャプションでもそのまま残す | 会話で「はずさなくてよい」 |
| R-13 | 既存のキャプション（タイトル・詳細・考察）の形式は変えない | 既存仕様の維持 |

### 固定タグ（R-04）

| カテゴリ | 固定タグ |
|---|---|
| 焙煎 | #コーヒー焙煎 #自家焙煎 #手鍋焙煎 #コーヒー好き |
| 縫物 | #手作り #ハンドメイド #手縫い #縫い物 |
| 染物 | #草木染め #手染め #染め物 |
| コーヒー店 | #カフェ巡り #コーヒー好き #コーヒー店巡り |
| コーヒー豆 | #コーヒー豆 #スペシャルティコーヒー #コーヒー好き |

### 動的タグの取得元（R-05）

| カテゴリ | 取得元の項目 | 例 |
|---|---|---|
| 焙煎 | 産地、農園、グレード、焙煎度 | #ニカラグア #サンタアナ農園 #SHG #深煎り |
| 縫物 | 制作物、対象 | #アロハシャツ #子ども |
| 染物 | タイトル先頭の染色方法（「 #」より前）、染めたものの材質 | #コーヒー染め #オックス |
| コーヒー店 | 店名（「＠」「(」「（」より前）、エリア（その後ろ） | #マーメイドコーヒー #明大前 |
| コーヒー豆 | 産地（「、」で分割）、焙煎度 | #ブラジル #グアテマラ #中煎り |

考察（insights）からはタグを作らない。

## 5. 制約

- Instagramの1投稿あたりのタグ上限は30個（R-11）
- キャプションは2200文字以内（現状は約380文字で、制限には達していない）
- 投稿処理そのものの動作（画像のコンテナ作成、公開の流れ）は変えない

| ID | 内容 | 確認方法 |
|---|---|---|

| AC-02 | 動的タグが表の項目から生成され、未入力の項目からはタグが作られない | 自動（node --test） |
| AC-03 | 重複・記号・空白の整形が R-06〜R-10 のとおりになる | 自動（node --test） |
| AC-04 | タグが30個を超える場合、固定タグを残して切られる | 自動（node --test） |

| AC-07 | 実際にInstagramへ投稿し、タグが表示される | 手動（トークンと実アカウントが必要） |

## 付録A: 学習ノート用

- 目的・経緯：投稿時にタグを手で付ける手間をなくしたい。やりたいことリストに追加していた項目（開発）
- 検討した案
  - A案：固定タグのみ。安定するが、投稿内容に合わない
  - B案：ログ内容からの動的タグのみ。内容に合うが、ぶれやすい
  - C案（採用）：固定タグ＋動的タグ。固定で傾向をそろえ、動的で内容に合わせる
- 採用理由：固定タグで投稿の傾向を安定させつつ、動的タグで個別の内容を拾えるため
- 残課題
  - インスタで実際に使われているタグの傾向を調べる（別タスク、やりたいことリストに登録済み）
  - 未確定事項 1〜3 の決定
